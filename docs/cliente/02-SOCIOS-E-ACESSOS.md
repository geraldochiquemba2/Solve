# Sócios e acessos

## Criar sócio

1. `/admin` → Clientes → Novo.
2. Preencher nome + telefone (**9 dígitos, sem 244**, ex.: 923000000).
3. Guardar e associar o plano/mensalidade.
4. Se for aluno de curso: confirmar email para a conta Cademi.

## Ver quem entrou hoje

1. `/admin` → Acesso físico.
2. Filtrar por **hoje**. Verde = entrada ok.
3. Clicar no nome para ver histórico do sócio.

## Catraca não abre

1. O plano está pago e **confirmado**? Se está pendente, ir a `01-CAIXA-E-PAGAMENTOS.md`.
2. Confirmar que o **PC do ginásio está ligado** e com internet
   (endereço interno `http://192.168.1.182:8080`).
3. Se o PC está ok e a catraca continua fechada: registar a entrada
   **manual** no caderno + no sistema, deixar o cliente treinar e avisar o técnico.
4. Detalhe em `04-O-QUE-FAZER-QUANDO.md`.

## Telefone errado / sócio duplicado

Não criar segundo registo. Procurar pelo telefone em Clientes, corrigir o número
e avisar o responsável para juntar os históricos.
