# Bem-vindo à SamoraFit — o seu sistema

Este guia é para quem trabalha no ginásio. Sem palavras técnicas.

## Endereços (guardar nos favoritos)

- **Admin (equipa):** https://solve-sqoh.onrender.com/admin
- **Portal (cliente):** https://solve-sqoh.onrender.com/conta
- **Saúde:** https://solve-sqoh.onrender.com/healthz (tem de dizer `ok`)

## O que o sistema faz (4 passos)

1. **Regista sócios** e mensalidades (`02-SOCIOS-E-ACESSOS.md`).
2. **Cobra** comMulticaixa Express ou Referência, conta comerciante **06100363**
   (`01-CAIXA-E-PAGAMENTOS.md`).
3. **Liberta o curso** na Cademi sozinho depois do pagamento confirmado
   (`03-CURSOS-CADEMI.md`).
4. **Mostra quem entrou** na catraca (`02-SOCIOS-E-ACESSOS.md`).

## Palavras que vai ver

- **Pendente** = à espera de pagamento. **Confirmado** = pago. **Expirado** = passou o prazo.
- **Multicaixa Express** = o cliente aprova no telefone dele.
- **Referência** = número para pagar no ATM ou aplicativo do banco.
- **Sincronizar** = botão que vai confirmar o estado real do pagamento no banco.

## Regras de ouro

1. Nunca cobrar duas vezes sem ver o extrato É-kwanza.
2. Só 1 cobrança pendente por aluno de cada vez.
3. Telefone do sócio sempre com 9 dígitos, sem 244 (ex.: 923000000).
4. Se algo falhar: `04-O-QUE-FAZER-QUANDO.md` → anotar hora + sócio + o que apareceu no ecrã.

Ordem de leitura: este ficheiro → `01` → `02` → `03` → `04`.
