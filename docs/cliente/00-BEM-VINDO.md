# Bem-vindo à SamoraFit — o seu sistema

Este guia é para quem trabalha no ginásio, sem palavras técnicas.

- **CRM admin (staff):** https://solve-sqoh.onrender.com/admin
- **Portal do cliente:** https://solve-sqoh.onrender.com/conta

O que o sistema faz:
1. Regista sócios e mensalidades.
2. Cobra com Multicaixa Express ou Referência (conta comerciante **06100363**).
3. Liberta o curso na Cademi sozinho após pagamento confirmado.
4. Mostra quem entrou na catraca.

Se algo falhar, abrir `04-O-QUE-FAZER-QUANDO.md`.
Glossário: **pendente** = à espera de pagamento; **confirmado** = pago;
**expirado** = passou o prazo; **Multicaixa Express** = aprova no telefone;
**Referência** = número para pagar no ATM/aplicativo.
