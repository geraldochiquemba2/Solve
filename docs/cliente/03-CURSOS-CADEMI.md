# Cursos Cademi

## Como funciona
Após pagamento **confirmado**, o curso liberta sozinho na conta Cademi do aluno.

## Se o curso não libertou
1. Confirmar que o pagamento está **confirmado** (não pendente).
2. `/admin` → Academia → ver estado da entrega.
3. Se "Com erro", abrir Vendas na Cademi e ler o motivo.
4. Libertar manualmente só após confirmar pagamento no extrato.
